## 📖 Overview

**Hack The AI** is an enterprise-grade, story-driven cyber investigation and threat simulation platform. It bridges the critical training gap across multi-layer modern digital infrastructures by immersing security analysts in simulated operations at the intersection of:
- 🤖 **Artificial Intelligence (AI):** Neural network inference, context injection, and training dataset poisoning.
- ⛓️ **Decentralized Ledgers (Web3):** Cross-chain bridge contracts, automated liquidity pools, and transaction forensics.
- 📡 **Industrial Internet of Things (IoT):** Edge gateway telemetry, synthetic jitter detection, and sensor aggregation.
- 🏛️ **Decentralized Consensus:** Byzantine Fault Tolerance (BFT) validator voting splits and poisoned oracle feeds.

* **XP Stakes:** 300 XP | **Duration:** 55-65 min

The corrupted feed enters the multi-sig oracle aggregator, inducing a 3:2 derived state fork in the validator cluster while the poisoned AI security sentinel suppresses critical volatility alarms.

## 💻 In-Browser Forensic Workstation OS Features

1. **Multi-Window Operating System:** Draggable, stackable, and minimizable windows with taskbar switching and traffic-light window controls.
2. **Simulated Burp Suite Inspector:** Tabbed HTTP/RPC proxy inspection with request/response dual-panes, repeater, and target trees.
3. **Forensic Terminal Shell:** Realistic interactive CLI console supporting `grep`, `python`, `iot-telemetry`, `policy`, `evidence`, and `whoami`.
4. **Case File Manager:** Monaco-style raw text file viewer for inspecting audit feeds, policy configs, and smart contract ABIs.
5. **Dynamic Attack Graph:** Interactive SVG node network illustrating the attacker's trajectory from initial ingress to root compromise.
6. **Live Telemetry & AI Studios:** Real-time dashboards visualizing validator topology splits, sensor streams, and AI confidence levels.
7. **Scratchpad Notes:** Auto-syncing local storage notebook preserving investigator notes throughout the case.
8. **Automated Progressive Hints & Capstones:** Tiered hints for hands-on tasks and a comprehensive final certification quiz.

## 🛠️ Technology Stack

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Backend Framework** | Python 3.12 / Flask 3.0 | WSGI application core with modular Blueprints |
| **Database & ORM** | SQLAlchemy / Flask-Migrate | Relational schema with SQLite `/tmp` serverless fallback |
| **Security Controls** | Flask-Talisman / Flask-WTF / Flask-Limiter | CSP security headers, CSRF token validation, and rate limiting |
| **Session Backend** | Signed Secure Cookies / Flask-Session | Persistent session tokens and serverless secret key derivation |
| **Frontend Architecture** | Semantic HTML5 / Jinja2 / Cyber CSS | Token-driven dark theme with custom responsive layout |
| **Workstation Logic** | Vanilla JavaScript (ES6+) | High-performance zero-dependency window manager & emulators |
| **Cloud Deployment** | Vercel Serverless Python | Edge serverless WSGI execution via `api/index.py` |

## 🚀 Local Quickstart

### Prerequisites
- Python 3.10+
- Git

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/lakshaysoni22/hack-the-ai.git
cd hack-the-ai

# 2. Create and activate a virtual environment
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Start the development server
python app.py
```
Open your browser and navigate to `http://127.0.0.1:5000/`.
